# MoriXterm 0.9.7

- Context menus are now positioned relative to the application overlay.
- Menus open downward by default.
- When there is not enough room below the pointer, the menu opens upward.
- Horizontal and vertical clamping keeps the entire menu visible inside the window.
- Applied to terminal, file manager, session, folder, and FTP/SFTP remote context menus.
- Repository links now target https://github.com/mortenaho/morixterm.
