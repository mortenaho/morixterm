# Push to GitHub

This package is already initialized as a Git repository.

- Remote: `https://github.com/mortenaho/morixterm.git`
- Prepared branch: `qt-rewrite`
- Commit: already created

The existing GitHub repository currently has its own `main` history, so this package intentionally uses the non-destructive `qt-rewrite` branch.

To publish it, run only:

```bash
git push
```

After the branch is on GitHub, it can be merged or used to replace `main` deliberately.
