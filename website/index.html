Quietly secure

Your keys.
Your control.

MoriXterm is designed to make the safe path the easy path. Credentials stay in the operating system vault, host keys are handled deliberately and legacy SSH algorithms are opt-in per connection.

Read the security policy ↗
✓

OS credential vault

Remembered passwords use Windows Credential Manager or libsecret instead of SQLite.

✓

Host-key awareness

Dedicated known-hosts storage, first-use acceptance and explicit changed-key replacement.

✓

No global weakening

Compatible and legacy SSH algorithms are selected per session, never silently enabled everywhere.
