# MoriXterm branding

Drop the official MoriXterm logo files here (do not redesign):

- `morixterm-logo.png` — full logo for splash, About, sidebar
- `morixterm-icon.png` — square app/installer icon (512×512 recommended)

Until those files are provided, the app uses `morixterm-logo.svg` as a temporary mark.
The SVG may be replaced wholesale; keep the filenames above so Electron Builder and UI paths stay stable.
